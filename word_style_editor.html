Typing inside an equation

Type / for a fraction, ^ for a power, _ for a subscript. Words like sqrt, pi, alpha, theta turn into symbols, and <= >= != -> become ≤ ≥ ≠ →. You can also type \ followed by any LaTeX command (for example \sum) and press Space. Space moves the cursor out of a fraction or root.
